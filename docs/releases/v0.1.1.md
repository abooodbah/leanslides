# LeanSlides v0.1.1

LeanSlides is a read-only viewer for PowerPoint presentations on Windows 10
and 11. It opens `.pptx`, `.ppsx`, `.potx`, `.pptm`, `.ppsm`, and `.potm`
files for reading and presenting. Macros, OLE objects, and ActiveX controls
never run, and nothing a file links to is fetched.

This release fixes a start-up problem. Nothing else changed.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows 10 and 11, x64 | **LeanSlides-v0.1.1-windows-x64.zip** |

The ZIP has an adjacent **LeanSlides-v0.1.1-windows-x64.zip.sha256** file,
and its build provenance is attested:

```powershell
gh attestation verify LeanSlides-v0.1.1-windows-x64.zip --repo abooodbah/leanslides
```

LeanSlides uses the Microsoft Edge WebView2 Runtime that Windows 10 and 11
already have. It does not bundle a browser.

## Fixed

Every LeanSlides window on a PC shares one WebView2 browser. Two states of
that browser stopped a new window from showing the presentation:

- The browser had stopped answering. The new window stayed blank for about
  40 seconds.
- The browser had been started with other settings, for example by another
  LeanSlides version. The new window showed "LeanSlides could not start".

Now a start that fails, or has not shown the reader after 20 seconds, is
tried once more with a second WebView2 folder,
`%LOCALAPPDATA%\LeanSlides\WebView2\Recovery`. On the test PC the window then
showed the presentation 20.4 seconds after it opened in the first case and
0.5 seconds after in the second. A normal start is unchanged and still shows
the first slide in about half a second. The new folder is inside the old one,
so uninstalling removes both.

## Known gaps

The gaps listed for
[v0.1.0](https://github.com/abooodbah/leanslides/releases/tag/v0.1.0) are
unchanged: charts, SmartArt, video, audio, and 3D models show their stored
picture; animations and transitions are not played; Windows x64 only.

## Installing

Extract the ZIP and run `LeanSlides.exe`, or install it for the current user
(no administrator rights) from the extracted folder:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -OpenDefaultAppsSettings
```

## Signing and privacy

The Windows programs in the GitHub ZIP are not signed. Windows may show an
unknown-publisher or SmartScreen warning; compare the ZIP with the `.sha256`
file before you run it.

Privacy policy: This program will not transfer any information to other
networked systems unless specifically requested by the user or the person
installing or operating it. LeanSlides's own code makes no network requests
and never fetches anything a presentation points to. The page is drawn by the
Microsoft Edge WebView2 Runtime, a Microsoft component, which may contact
Microsoft on its own. The full policy, including how to uninstall, is in the
[README](https://github.com/abooodbah/leanslides#privacy-policy).
