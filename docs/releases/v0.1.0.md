# LeanSlides v0.1.0

The first release of LeanSlides, a read-only viewer for PowerPoint
presentations on Windows 10 and 11. It opens `.pptx`, `.ppsx`, `.potx`,
`.pptm`, `.ppsm`, and `.potm` files for reading and presenting. Macros, OLE
objects, and ActiveX controls never run, and nothing a file links to is
fetched.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows 10 and 11, x64 | **LeanSlides-v0.1.0-windows-x64.zip** |

The ZIP has an adjacent **LeanSlides-v0.1.0-windows-x64.zip.sha256** file,
and its build provenance is attested:

```powershell
gh attestation verify LeanSlides-v0.1.0-windows-x64.zip --repo abooodbah/leanslides
```

LeanSlides uses the Microsoft Edge WebView2 Runtime that Windows 10 and 11
already have. It does not bundle a browser.

## What it does

- Slide thumbnails; arrow keys, Page Up and Page Down, Home and End; fit and
  zoom.
- F5 presents from the first slide, Shift+F5 from the current one, and Esc
  leaves the presentation.
- Speaker notes, find across slides (Ctrl+F), and copying slide text.
- Tabs (Ctrl+Tab, Ctrl+W, Ctrl+1 to Ctrl+9), five themes, a settings page
  with the keyboard shortcuts, and an interface in English, Simplified
  Chinese, and Japanese.
- Placeholders inherit from their layout and master; theme colours and
  fonts, bullets, autofit, preset shapes, fills, lines, cropped pictures,
  tables, groups, and backgrounds are drawn.

## How close it is to PowerPoint

Measured on 2026-11-25 against PowerPoint 16.0's own export of every slide,
over 550 slides from 145 public decks (`tests/parity/README.md`):

- Of PowerPoint's 3,130 text lines, LeanSlides wrote 2,992 (95.6%) the same
  way on one line.
- The median structural similarity (SSIM) of a slide is 0.88, against 0.74
  for an empty slide with the right background.
- The median gain, how far the drawing moves that score from the empty slide
  towards identical, is 0.41. 63 of 531 slides score below their empty
  slide.

## Start-up time and memory

Measured on 2026-11-25 on an Intel Core i7-13620H laptop with Windows 11 and
WebView2 158, medians of 10 launches (`tests/perf/README.md`). Memory is the
private memory of LeanSlides.exe and every WebView2 process it started, once
it has settled.

| Deck | First slide drawn | Memory |
| --- | ---: | ---: |
| none (start page ready) | 424 ms | 89.4 MiB |
| 3 slides, 8 KB | 450 ms | 91.9 MiB |
| 23 slides, 0.9 MB | 455 ms | 99.0 MiB |
| 240 slides with a picture each, 46 MB | 513 ms | 150.8 MiB |
| the same, after paging through every slide | | 294.4 MiB |

The window is visible after about 115 ms in every case.

## Known gaps

- Charts, SmartArt, ActiveX controls, video, audio, 3D models, and ink are
  not drawn. Each shows the picture the file stores for it, or a labelled
  box when there is none.
- In some decks all text is drawn about 20 pixels lower than in PowerPoint.
- Vertical text in table cells is drawn horizontally, and some table-style
  header text has the wrong colour.
- Double and triple (compound) lines are drawn as one line.
- A font the deck asks for that is not installed is replaced by a similar
  one, so line breaks can differ.
- Memory keeps growing while the same large deck is paged through again and
  again: 523 MiB after five walks through the 240-picture deck.
- Animations and transitions are not played; the presentation shows each
  slide in its final state.
- Windows only, x64 only.

## Installing

Extract the ZIP and run `LeanSlides.exe`, or install it for the current user
(no administrator rights) from the extracted folder:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -OpenDefaultAppsSettings
```

## Signing and privacy

The Windows programs in the GitHub ZIP are not signed. Windows may show an
unknown-publisher or SmartScreen warning; compare the ZIP with the `.sha256`
file before you run it.

Privacy policy: This program will not transfer any information to other
networked systems unless specifically requested by the user or the person
installing or operating it. LeanSlides's own code makes no network requests
and never fetches anything a presentation points to. The page is drawn by the
Microsoft Edge WebView2 Runtime, a Microsoft component, which may contact
Microsoft on its own. On the measuring PC, LeanSlides.exe opened no socket
and the page requested only its own reader addresses, while the runtime
opened HTTPS connections to Microsoft 365 addresses
([docs/HOST.md](https://github.com/abooodbah/leanslides/blob/main/docs/HOST.md#network)). The full policy, including how to uninstall, is in the
[README](https://github.com/abooodbah/leanslides#privacy-policy).
