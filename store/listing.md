## English (United States), en-US

### Short title (50 characters or fewer)

LeanSlides

### Short description

Read and present slide decks. Macros and embedded objects never run.

(68 characters.)

### Description

LeanSlides opens presentation files for reading and presenting. It is a read-only viewer: you can look at the slides, present them, and copy their text, but you cannot edit them.

It opens .pptx, .ppsx, and .potx files, and the macro-enabled .pptm, .ppsm, and .potm files. Macros, OLE objects, and ActiveX controls never run, and nothing a file links to is fetched from the internet.

Slide thumbnails sit beside the current slide. Move between slides with the keyboard, fit the slide to the window or zoom in, and press F5 to present full screen. You can show the speaker notes, find text across all slides, and open several files as tabs in one window.

Charts, SmartArt, video, and similar objects show the picture the file stores for them, or a labelled box where there is none.

Five themes. The interface is in English, Simplified Chinese, and Japanese. No account, no ads, and no telemetry.

LeanSlides draws slides with the Microsoft Edge WebView2 Runtime that Windows provides. It is free and open source under the MIT License.

### Product features

- Opens .pptx, .ppsx, and .potx presentations
- Opens macro-enabled .pptm, .ppsm, and .potm files without running their macros
- Macros, OLE objects, and ActiveX controls never run
- Nothing a file links to is fetched
- Slide thumbnails and keyboard navigation
- Fit to window and zoom
- Press F5 to present full screen
- Speaker notes
- Find text across all slides
- Copy the text of a slide
- Several files open as tabs in one window
- Charts, SmartArt, and video show the stored picture or a labelled box
- Five themes
- Interface in English, Simplified Chinese, and Japanese
- No account, no ads, no telemetry
- Free and open source (MIT License)
