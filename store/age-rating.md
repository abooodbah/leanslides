# LeanSlides age rating (IARC questionnaire)

Partner Center > Submission > Age ratings. Answer as follows. LeanSlides is a
read-only presentation viewer: it shows files that are already on the user's
PC. It has no accounts, no chat, no sharing, no ads, and no purchases, and it
collects no data.

| Question | Answer |

| Offensive language or crude humor | No |

| Gambling or simulated gambling | No |
| Fear or horror content | No |
| Can users interact or communicate with each other (chat, comments, posts) | No |
| Does the app share the user's current physical location with other users | No |
| Does the app allow purchases of digital goods | No |
| Does the app contain user-generated content shared between users | No. It shows only the user's own local files. |
| Does the app give unrestricted access to the internet (for example a web browser) | No. A web or email link in a slide opens in the user's own browser or mail app only after a click. |
| Does the app collect or share personal information | No |

Expected result: the lowest rating in every system (for example IARC 3+,
ESRB Everyone, PEGI 3). If the questionnaire asks a question that is not
listed here, the answer for LeanSlides is No.
